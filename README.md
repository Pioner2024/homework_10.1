# Проэкт feature/homework_10_1
## Описание:
Данный проэкт предназначены для маскировки конфиденциальных данных банковских карт и счетов, чтобы обеспечить безопасность при отображении информации в пользовательском интерфейсе.
## Устоновка:
1.Копируйте репозиторий:
```shell
git clone git@github.com:Pioner2024/homework_10.1.git
```

## Использование:
Чтобы воспользоваться функциями маскировки номеров карт и счетов, выполните следующие шаги:

1. Импортируйте функции в ваш проект или скрипт (если они реализованы в виде модуля).

2. Передайте в функцию строку с номером карты или счета в виде последовательности цифр без пробелов или других символов.

3. Получите маскированный номер, вызвав соответствующую функцию.

### Пример использования: 


#### Маскировка номера карты:
```
card_number = "7000792289606361"
masked_card = get_mask_card_number(card_number)
print(masked_card)  # Вывод: 7000 79** **** 6361
```
#### Маскировка номера счета:
```
account_number = "73654108430135874305"
masked_account = get_mask_account(account_number)
print(masked_account)  # Вывод: **4305
```
