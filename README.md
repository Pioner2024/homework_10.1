# Проект "Маскировка данных и обработка транзакций"

Этот проект содержит модули для маскировки номеров карт и счетов, обработки данных о транзакциях и отображения информации в удобном виде.

---

## Структура проекта

- **Модуль `masks.py`**  
  Содержит функции для маскировки номеров карт и счетов:
  - `get_mask_card_number(card_number: str) -> str` — возвращает маскированный номер карты.
  - `get_mask_account(account_number: str) -> str` — возвращает маскированный номер счета.

- **Модуль `widget.py`**  
  Использует функции из `masks.py` для обработки данных пользователя:
  - `mask_account_card(card_number: str) -> str` — маскирует номер карты или счета, учитывая наличие ключевых слов (например, "Visa") в строке.
  - `get_date(correct: str) -> str` — форматирует дату из строки в формат `ДД.ММ.ГГГГ`.
  
- **Обработка данных о транзакциях** (например, в `processing.py`)  
  Включает функции:
  - `filter_by_state(opz: str = "EXECUTED") -> list[dict]` — фильтрует список транзакций по статусу.
  - `sort_by_date(sliv: list[dict], descending: bool = True) -> list[dict]` — сортирует транзакции по дате.

---

## Основные функции

### Маскировка номеров

- `get_mask_card_number(card_number: str)`  
  Принимает номер карты, извлекает только цифры и возвращает строку в виде:  
  `XXXX XX** **** XXXX`

- `get_mask_account(account_number: str)`  
  Принимает номер счета и возвращает:  
  `Счет **XXXX`

### Обработка данных о транзакциях

- `filter_by_state(opz: str)`  
  Возвращает список транзакций со статусом `opz`.

- `sort_by_date(sliv, descending)`  
  Сортирует список транзакций по дате, по убыванию или возрастанию.

### Взаимодействие с пользователем

- Ввод номера карты или счета с помощью `input()`.
- Отображение маскированных данных.
- Обработка дат в форматированной форме.

## Как использовать

1. **Установка**

Этот проект не требует специальных зависимостей. Просто скопируйте файлы в папку проекта и используйте их.



2. **Запуск программы**

Создайте файл `main.py` и импортируйте нужные модули, например:

```python
from widget import mask_account_card, get_date
from processing import input_data, filter_by_state, sort_by_date

# Взаимодействие с пользователем
card_number = input("Введите номер карты: ")
print(mask_account_card(card_number))

account_number = input("Введите номер счёта: ")
print(get_mask_account(account_number))

# Обработка данных о транзакциях
filtered = filter_by_state("EXECUTED")
print(filtered)

sorted_transactions = sort_by_date(input_data, descending=False)
print(sorted_transactions)

# Форматирование даты
date_str = "2019-07-03T18:35:29.512364"
print(get_date(date_str))
```

Запустите `main.py`:

```bash
python main.py
```
